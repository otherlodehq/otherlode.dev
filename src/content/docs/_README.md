# Docs content

Each folder here is one section of `/docs`. `start/` is written in this
repo. `agent/`, `collector/` and `server/` are copied from each source
repo's `docs/site/` by `scripts/sync-docs.sh`, so edit those pages in
their source repo. A file whose name starts with `_`, like this one, is
not a page. The site's README has the page format.
